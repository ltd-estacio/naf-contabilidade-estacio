Perfeito, na parte de "Backup Atendimentos" do painel do coordenador, la em baixo tem "Download Direto" e "Enviar por E-mail" (com base na imagem anexada), tem que melhorar a parte de "Enviar por E-mail" para enviar automaticamente o backup por e-mail. O e-mail deve ser enviado para o e-mail do coordenador que está logado no sistema. Tem que utilizar o mesmo template de email do arquivo email-backup-template-old.html que já está no projeto. O e-mail deve ser enviado utilizando o serviço nodemailer, que já está configurado no sistema. O e-mail deve conter o backup em anexo no formato JSON, com o nome do arquivo seguindo o padrão: backup_naf_YYYY-MM-DD_ID.json, onde YYYY-MM-DD é a data atual e ID é o ID do backup gerado no banco de dados. O corpo do e-mail deve conter as seguintes informações:
- Data e hora do backup
- Total de registros no backup
- Número de tabelas incluídas no backup
- Número de estudantes incluídos no backup
- Nome e e-mail do coordenador que solicitou o backup
Além disso, o e-mail deve ter um botão "📥 Baixar Backup Completo"
que redirecione para um link de download do backup (esse link pode ser uma rota temporária no backend que permita o download do arquivo JSON). Certifique-se de que o e-mail seja formatado corretamente e que todas as informações estejam claras para o coordenador. Após implementar essa funcionalidade, teste enviando um backup por e-mail para garantir que tudo esteja funcionando conforme o esperado.
