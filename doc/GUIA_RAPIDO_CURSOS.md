# 🚀 GUIA RÁPIDO - NOVA FUNCIONALIDADE DE CURSOS

## ⚡ Em 3 Passos

### 1️⃣ EXECUTAR SQL (2 minutos)
```
1. Acesse: https://supabase.com/dashboard
2. Selecione seu projeto NAF
3. Vá em "SQL Editor"
4. Cole o arquivo: /database/migrations/20251026_popular_cursos_externos.sql
5. Clique em "RUN"
6. ✅ 14 cursos adicionados!
```

### 2️⃣ TESTAR COORDENADOR (3 minutos)
```
1. Acesse: https://naf.ltdestacio.com.br
2. Login como coordenador
3. Olhe o menu horizontal de navegação
4. Você verá o novo card: "Cursos Estudantes" 📚
   (Entre "Perigo" ⚠️ e "Automação Fiscal" 🤖)
5. Clique nele
6. Você verá todos os 14 cursos que acabou de adicionar
7. Teste criar um novo curso
8. Teste ativar/desativar um curso
```

### 3️⃣ TESTAR ESTUDANTE (2 minutos)
```
1. Login no portal estudantil
2. Clique na aba "Treinamentos"
3. Verá 4 abas:
   - Cursos Internos
   - Cursos Externos ← AQUI!
   - Manuais
   - Legislação
4. Clique em "Cursos Externos"
5. Veja os 14 cursos listados
6. Clique em "Acessar Curso" em qualquer um
7. Curso abre em nova aba (Escola Virtual Gov.br)
8. Volte ao painel do coordenador
9. Veja o contador de views aumentar!
```
